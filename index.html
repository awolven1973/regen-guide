Regen Guide

A developing, college-level guide to generative objects, declarative attributes, composition, and protocols in Regen. Assumes familiarity with Common Lisp.

Editorial scope. These opening chapters explain concepts. They do not invent defobject syntax or present proposed features as implemented. Technical examples will be verified against source before publication.

Reference

Planned progression

  1. Defining objects using defobject. Concrete examples after verifying the implementation's syntax.
  2. Attribute evaluation and assignment. Computed values, explicit overrides, and invalidation.
  3. Composition and dependency graphs. Separate instance hierarchy from computation dependencies.
  4. Reference systems and geometry. Coordinate systems and geometric transformations.
  5. Consistency and recovery. Existing behavior and proposed transactional mechanisms, clearly distinguished.
  6. Protocols and backends. Interfaces, conformance, and mappings to independent implementations.

How to read

Each chapter has permanent section links. Definitions link into the terminology index, and index entries lead back to the most relevant explanatory sections. The guide is fully static, so the files can also be read offline.
